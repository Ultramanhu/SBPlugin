# 08 实施路线图

## 里程碑总览

| 里程碑 | 目标 | 主要交付物 | 验收标准 |
|---|---|---|---|
| **M0 技术验证**（约 1 周） | 打通关键技术风险 | 3 个 spike 原型 | 见 §1 |
| **M1 语言核心**（约 2 周） | 双引擎可用 + 测试全绿 | sb-lang-core 包；VS 侧编译器引用；一致性测试集 v1 | 两侧既有测试 + 一致性测试全过 |
| **M2 编辑体验 MVP**（约 3 周） | 文件创建/着色/IntelliSense/运行 | VS Code 扩展 MVP + VSIX MVP | 见 §3 |
| **M3 调试**（约 2 周） | 双端 DAP 调试 | sb-debug + SB.DebugAdapter | 调试 DSL 场景全过，双端 F5 可用 |
| **M4 图形库与发布**（约 3-4 周） | GraphicsWindow + 市场上架 | Webview/WPF 图形宿主；CI 发布管线 | 教学示例程序（弹球/海龟）双端运行 |

## 1. M0 技术验证（Spike）

| Spike | 内容 | 通过条件 |
|---|---|---|
| S1 | 拷贝 `SmallBasic.Compiler`/`SmallBasic.Utilities`/`SmallBasic.Tests` 源码至 `VisualStudioPlugin`，升级为 SDK 风格项目（netstandard2.0 库 + net8.0 测试，.NET 8 SDK 构建，摘除旧 StyleCop/FxCop） | 全部既有测试在 net8.0 下通过；`UPSTREAM.md` 记录来源哈希 |
| S2 | 拷贝 `SmallBasicOnline/src/compiler`+`tests/compiler` 至 `packages/sb-lang-core`，升级 TS 5.x + vitest + Node 20 | 既有 jasmine 用例平移后全绿 |
| S3 | VS Debug Adapter Host 挂载一个玩具 DAP 适配器，验证 9 个关键请求（见 05 §4） | setBreakpoints/launch/stackTrace/variables/continue/next/pause/terminate/runInTerminal 行为明确，限制记录在案 |

## 2. M1 语言核心

- `VisualStudioCodePlugin` monorepo 骨架；`sb-lang-core` 拷贝升级完成（TS 5.x / vitest / eslint 9；严格模式渐进计划立项；`UPSTREAM.md` 就位）。
- `VisualStudioPlugin` 解决方案骨架；`SB.Compiler`/`SB.Utilities`/`SB.Compiler.Tests` 拷贝升级完成（SDK 风格、最新 LangVersion、NetAnalyzers；net8.0 测试全绿）。
- `conformance/` 一致性测试集 v1（语句/表达式/8 个 MVP 库/事件），双 runner 接入 CI。
- library-docs 生成脚本跑通，与双引擎元数据对账告警接入构建。

## 3. M2 编辑体验 MVP

**VS Code**：TextMate 语法、language-configuration、补全/悬停/诊断/签名帮助、语义令牌、`smallbasic.newFile`/`smallbasic.run`（终端 TextWindow）、打包流水线。

**VS**：内容类型与 `.sb` 关联、IClassifier、AsyncCompletion、QuickInfo、ErrorTagger、项模板、新建文件命令、`SB.RunHost` 控制台运行。

**M2 验收（双端）**：
1. 新建 `hello.sb` → 输入 `TextWindow.WriteLine("Hello")` 有补全与悬停文档；
2. 故意写错（缺 `EndIf`）→ 波浪线 + 错误面板条目，行列正确；
3. 运行 → 终端输出 `Hello`；含 `Read` 的程序可交互输入；
4. 一致性测试集 + 着色快照测试 CI 全绿；
5. 性能预算达成：1k 行编译 <5ms、补全 <30ms（基准报告产出）。

## 4. M3 调试

- TS 适配器 + VS Code debugger contribution；
- .NET 适配器 + Debug Adapter Host 注册 + 终端 I/O 桥；
- 断点吸附、stepIn/next/stepOut、变量/调用栈、异常停止、暂停；
- `conformance/debug/` 场景双端对跑。

**M3 验收**：调试 DSL 全部场景双端一致通过；教学示例断点调试人工走查（VS Code 与 VS 2026 各一遍）。

## 5. M4 图形库与发布

- VS Code Webview GraphicsWindow（Canvas 2D，Shapes/Turtle/Mouse/Key 事件）；
- VS WPF GraphicsWindow（SB.RunHost --graphics）；
- **双后端可选**收尾（ADR-5）：VS Code 侧 .NET 后端按需下载通道、VS 侧 node 后端捆绑与 Node 检测引导；两端"IDE × 备选后端"冒烟用例进 CI；
- File/Network 安全策略落地；
- Walkthrough/入门引导、图标与商店素材；
- Marketplace 与 VS Marketplace 发布（预览通道）。

**M4 验收**：官方教程示例（弹球游戏、海龟分形，取自 HomeSite `tutorial-downloads` 的 `.sb` 样例）双端原样运行成功。

## 6. 依赖与并行策略

```
M0(S1,S2 并行; S3 独立) ──> M1 ──> M2(两端并行) ──> M3(两端并行) ──> M4
                                        │                  │
                                  一致性测试集从 M1 起持续扩充，作为所有后续里程碑门禁
```

- VS Code 线与 VS 线可由两人/两阶段并行推进；共享资产（一致性测试集、library-docs 生成器）在 M1 冻结接口。
- 每个里程碑结束更新本文档与实际偏差记录（轻量回顾）。
